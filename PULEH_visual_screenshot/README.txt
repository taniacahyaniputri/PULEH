PULEH — dashboard visual mengikuti screenshot yang dikirim.

Menjalankan:
1. Ekstrak ZIP.
2. Buka folder PULEH_visual_screenshot di VS Code.
3. Install ekstensi Live Server bila belum ada.
4. Klik kanan index.html > Open with Live Server.

Fitur demo:
- Dashboard utama dengan lima tahap REACH, ASSESS, CARE, CONNECT, CONTINUE.
- Sidebar dan kartu tahap dapat diklik untuk membuka halaman masing-masing.
- Peta Leaflet dengan basemap Esri dan marker wilayah referensi Aceh.
- Ringkasan layanan dan pilihan periode (angka simulasi).
- Formulir contoh di halaman tahap layanan.

Catatan:
Ini prototipe frontend. Data statistik adalah simulasi. Titik peta adalah referensi pusat administratif, bukan lokasi terdampak, posko, atau konselor. Status wilayah wajib diverifikasi dari BPBA/BPBD sebelum dipakai untuk penugasan. Belum ada backend, autentikasi, database, atau sinkronisasi. Jangan masukkan data pribadi penyintas nyata.
Peta dan font membutuhkan internet.
